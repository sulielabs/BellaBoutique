# بيلا بوتيك — إعادة صياغة النص العربي

**٣٩ ملف.** يشمل كل ما سبق (العربية افتراضية · ترتيب الرئيسية · زر واتساب يمين) **بالإضافة إلى** إعادة صياغة العربي.

## نص البطل

> **الفخامة، بثقة.**
> حقائب مصممين أصلية مستعملة. نفحص كل قطعة عند جهة مستقلة، ونصف حالتها بصدق قبل أن تصلك.

"بريلفد" بقيت في `meta description` والـJSON-LD فقط — يبحث بها بعض الناس. حُذفت من النص الظاهر.

## تصحيحات مفردة

- **ديونيسوس** — "بيج وإيبوني مع شامواه توب" ← **"بيج وبني داكن مع شامواه بني رمادي"**. إيبوني وتوب أسماء ألوان إنجليزية لا تعني شيئاً بالعربي.
- **برادا جاليريا وردي** — "وردي عاري" ← **"وردي هادئ"** (في الاسم والميتا والـJSON-LD وواتساب أيضاً). ووصف السافيانو صار "الجلد المحفور بخطوط متقاطعة".
- **برادا WOC** — "جلد ملمّع بلمعة عالية" كان يناقض `Brushed leather` ← **"جلد مصقول بلمعة هادئة"**.
- **برادا توت** — "جراب" تعني غطاء جوال خليجياً ← **"حقيبة صغيرة"**. و"شريحة NFC" ← "شريحة تحقّق إلكترونية".
- **شانيل WOC** — المقارنة كانت "أقوى من جلد الحمل" ← **"يقاوم الخدوش أكثر من الجلد الأملس"**.
- **ليدي ديور رمادي** — "شرحة حرير" ← **"ربطة حرير"**.
- **لو كاغول** — "الموتوربايك" ← **"الموتورسايكل"**، و"دلاية المرآة" ← "المرآة المعلّقة".
- **شانيل سبورتس** — "أفادت البائعة" ← **"ذكرت المالكة السابقة"**.
- **كامبون** — "غرافيك" ← "رسومات"، و"الأتيليه" ← "دار الأزياء".
- **جيت ديوال** — "الأناغرام" ← **"شعار لويفي"**.
- **دوفين** — "قفل LV الملتوي" ← **"الدوّار"**، و"خالدة" ← "كلاسيكية".

أسماء الموديلات والخامات بقيت منقولة كما هي: شامواه · ماتلاسيه · سافيانو · كانّاج · سوبريم · أوبليك · ديونيسوس · هورسبيت · غران دو بودر.

## سكربتان مرفقان

- `fix-arabic-default.py` — العربية افتراضية لأي صفحة جديدة
- `fix-arabic-copy.py` — توحيد المصطلحات

## لم يتغيّر

الإنجليزي كما هو. الأسعار والمقاسات والحالات كما هي. الـJSON-LD صالح في الـ٣٩ ملفاً، والجافاسكربت مفحوص.
