# بيلا بوتيك — العربية أولاً + إعادة ترتيب الرئيسية

**٣٧ ملف HTML معدّل.** انسخيها فوق جذر المستودع مباشرة.

## ما تغيّر

### كل الصفحات (٣٧)
- `<html lang="ar" dir="rtl">` بدل `en/ltr` — يمنع ومضة الإنجليزي قبل تحميل الجافاسكربت
- اللغة الافتراضية **عربي**. اختيار "English" يُحفظ في `bella_lang` ويستمر عبر كل الصفحات
- القراءة والكتابة داخل `try/catch` — سفاري في الوضع الخاص يرمي خطأً عند `localStorage` ويكسر زر اللغة كليًا

### `index.html` فقط
- **ترتيب الأقسام:** البطل ← الشريط المتحرك ← **المنتجات** ← لماذا بيلا ← الأصالة ← الأسئلة ← التواصل
- `PAGE_SIZE` من ٦ إلى **١٢**
- **حقائب الإعلان مثبّتة أولاً:**
  ```js
  const PINNED = ["lady-dior-grey","lv-dauphine","dior-bobby","chanel-frame"];
  ```
  ثم البقية بحسب الأحدث إضافةً، والمباعة دائمًا في الآخر.

## ⚠️ ملف ناقص

`product-dior-bobby.html` (بوبي أسود) **غير موجود** في ما رفعتِه — وهو أحد حقائب الإعلان المثبّتة الأربع.

الكرت سيظهر في المرتبة الثالثة ويقود إلى صفحة ٤٠٤. شغّلي السكربت عليه في المستودع:

```bash
python3 fix-arabic-default.py
```

يعدّل أي ملف HTML لم يُعدّل بعد، ويتجاهل المعدّل — آمن لو شغّلتيه أكثر من مرة.

## التحقق بعد النشر

- افتحي `bellasa.net` من الجوال: عربي، من اليمين لليسار، المنتجات ظاهرة بلا تمرير طويل
- بدّلي لإنجليزي ← افتحي صفحة منتج ← لازم تبقى إنجليزي
- اضغطي كرت بوبي أسود ← تأكدي أنه يفتح ولا يعطي ٤٠٤
- راقبي `ViewContent` في Events Manager: كان ٢٥ مقابل ٢,٣٩٤ زيارة
